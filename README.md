# 🌴 IslandCompass – Discover the Pearl of the Indian Ocean

### Your Ultimate Guide to Exploring Sri Lanka

---

## 📌 Project Overview

**IslandCompass** is a Sri Lankan based travel guide website designed to help local and international travellers discover the beauty, culture, heritage and natural attractions of Sri Lanka.

The platform provides information about popular tourist destinations, unique travel experiences, attractions, and travel recommendations across the island. It aims to make exploring Sri Lanka easier by bringing essential travel information together in one accessible and user friendly platform.

From golden beaches and breathtaking mountains to ancient historical sites and wildlife sanctuaries, IslandCompass helps travellers explore everything Sri Lanka has to offer.

This project is developed as a **frontend web development project** using HTML, CSS and JavaScript.

---

## 🎯 Project Objectives

- Provide a centralized platform for discovering tourist destinations in Sri Lanka.
- Promote Sri Lanka's cultural heritage, natural beauty and tourism.
- Provide useful information about tourist attractions and travel experiences.
- Help travellers explore destinations based on their interests.
- Offer a simple and interactive trip planning interface.
- Create a responsive and user friendly website accessible across different devices.

## ⚙️ Installation and Setup

Follow these steps to run IslandCompass locally.

### Prerequisites

Make sure you have the following installed:

- Git
- Visual Studio Code
- Google Chrome or another modern web browser
- Live Server extension for VS Code

### Step 1 – Clone the Repository

Open your terminal and execute:

```bash
git clone https://github.com/YOUR-USERNAME/IslandCompass.git
```

### Step 2 – Navigate to the Project Directory

```bash
cd IslandCompass
```

### Step 3 – Open the Project in VS Code

```bash
code .
```

### Step 4 – Run the Website

1. Open `index.html` in Visual Studio Code.
2. Right-click inside the file.
3. Select **Open with Live Server**.
4. The website will open in your default browser.

## 📄 Project Scope

IslandCompass is developed as a frontend-only web application.

All interactive features are implemented using HTML, CSS and JavaScript. Destination information and other sample content are handled on the client side.

The project does not currently include:

- Backend development.
- Database integration.
- User authentication.
- Online payment processing.
- Live hotel or transport reservations.
