# 🌴 IslandCompass – Discover the Pearl of the Indian Ocean

### Your guide to exploring Sri Lanka

IslandCompass is a frontend-only Sri Lankan travel guide website. It helps local and international travellers discover destinations, experiences, cultural heritage and natural attractions across the island.

## Project objectives
- Present Sri Lankan destinations and travel inspiration in one place.
- Help visitors explore by interests such as adventure, wildlife, beaches and heritage.
- Provide a responsive and accessible browsing experience.
- Offer a frontend trip-planning interface.

## Planned website sections
- **Home:** introduction, destination search and featured content.
- **Destinations:** destination listings, search and category filters.
- **Destination details:** destination descriptions, attractions, galleries and travel tips.
- **Experiences:** overview of activities and experience categories.
- **Explore Trips:** curated inspiration for adventure, wildlife, beach and cultural journeys.
- **Trip Planner:** frontend itinerary suggestions.
- **About & Contact:** project information and contact form.

## Technologies
HTML5, CSS3 and vanilla JavaScript. Google Fonts and Font Awesome are used for typography and icons. No backend or database is required for this project.

## Run locally
1. Clone the repository:
   ```bash
   git clone https://github.com/AnjeloRodrigo7/IslandCompass.git
   ```
2. Open the folder in Visual Studio Code.
3. Run `index.html` with the Live Server extension.

## Git collaboration
Use feature branches for assigned work, commit with descriptive messages, push changes and open a pull request for review before merging into `main`.

## Project scope
This is a frontend-only academic project. It does not currently include backend services, database integration, authentication, payments or live reservations.
